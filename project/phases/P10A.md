## Goal and acceptance

Implement private bounded SQLite WAL metadata, durable single-active FIFO admission, cancellation/timeout transitions and conservative restart recovery. Accept only classified nonsecret metadata; reject unsafe paths, corruption, incompatible schema and ambiguous initialization. Persist before returning normal results, and block use after ambiguous storage errors until reopen/reconciliation. Test restart/process death, concurrency, capacity/freshness/headroom, timestamps/states, bounds and failures. Provide a CGO-free pinned dependency, independent review and exact CI evidence.

No executor, public API/UI, prompt store, hard VRAM isolation, arbitrary host execution, physical disk operation, production migration, release or deployment is included. A queued row is metadata, not an executable backlog.

## Design and files

See [compute queue contract](../../docs/architecture/compute-queue.md), [F09](../features/F09-gpu-job-scheduling.md), and [next work](NEXT.md). Code: `internal/jobqueue/{types.go,store_linux.go,store_linux_test.go}`, public acceptance: `tests/jobqueue/acceptance_test.go`; pinned `go.mod`/`go.sum`; `.github/workflows/ci.yml` adds explicit no-CGO and race coverage. The project map also records P09G merged and F09 partial.

SQLite schema version `1`, WAL/FULL, parent directory sync, private mode `0700` directory/mode `0600` singly linked files and one lifetime owner lock. Ancestors must be root/current UID owned and nonwritable by others, except root-owned sticky directories. Strict kind/ID/resource/time/state validation; exact schema/integrity checks; existing zero/missing known database and orphan sidecars fail closed. No automatic initialization over missing history, migration, repair or retention deletion.

Bounds: 1,024 queued / 10,000 total retained records; 16 MiB main DB / 17 MiB WAL / 64 KiB shared-memory file; bounded recovery reads; one SQLite connection, no cache spill and truncate checkpoint after each commit. Full retained-store tests verify a terminal update still works and history is not evicted. Filesystem free blocks are not reserved; real I/O failure can still occur.

One active metadata reservation; strict FIFO means an oversized oldest row blocks later rows. Snapshot must be sane, nonfuture and fresh. Request plus headroom must fit free capacity and configured budget. Exact deadline wins over a late success/cancel request. Queued metadata persists; reopening interrupts previous in-flight metadata without replay. `running` records a granted reservation, not observed execution. Future dispatch must confirm quiescence/fencing before relying on cancellation, timeout or restart to free physical capacity.

Real SQLite read-only write denial and injected checkpoint failure after real commit prove error/zero-result behavior and poisoned-writer reconciliation for enqueue/admit/expire/finish/cancel. An ambiguous commit may already be durable; callers must reopen/read state rather than blindly retry.
