# LOCAS OS

Local-first headless AI compute appliance, currently delivered as a dedicated Ubuntu 24.04 WSL2 development preview with Go services and an embedded local dashboard.

Start with the [project map](project/README.md) for feature status and guardrails, [phase plans](project/PHASES.md), [review findings](project/REVIEW.md), and [parallel component workflow](project/PARALLEL_WORK.md). For installation and operational procedures, see [WSL documentation](packaging/wsl/README.md), taking account of its current review notice.

Source exists for telemetry, administrator enrollment, optional Ollama/Open WebUI, approved app installation and signed updates. Release qualification remains incomplete; durable GPU workload scheduling and SQLite storage remain planned. Do not interpret implementation as production certification.
